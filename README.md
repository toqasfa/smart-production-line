# MQTT to Firebase Bridge - Smart Line Project

ده السكريبت اللي بيربط مشروع خط الإنتاج بقاعدة البيانات السحابية (Firebase). الفكرة كلها إن الراسبيري باي بتستقبل قراءات الحساسات لحظة بلحظة عن طريق الـ MQTT، والسكريبت ده بياخد البيانات دي ينظمها ويبعتها على طول لـ Firestore عشان تظهر على الـ Dashboard.

## الحساسات والبيانات اللي بنرفعها:
* Weight Topic: بنستقبل منه قراءة الميزان (Load Cell) وبنحدث الوزن الحالي وآخر وزن اتسجل في الـ Database.
* RFID Topic: ده مخصص للمنتجات السليمة (Good Products)، أول ما كارت يعدي بنزود عداد القطع السليمة والإجمالي وبنخلي الحالة NORMAL.
* Ultrasonic Topic: مخصص للمنتجات التالفة (Faulty)، لو الحساس لقط جسم تالف بنزود عداد التوالف والإجمالي وبنغير الحالة لـ DIVERT عشان يحول مسار القطعة.

## تشغيل السكريبت (Libraries):
عشان تشغل الكود على الراسبيري باي، هتحتاج بس تسطب المكتبات دي الأول:
pip install paho-mqtt firebase-admin


ملاحظة أمنية:
ملف الـ serviceAccountKey.json الخاص بصلاحيات الفايربيز مش مرفوع هنا على جيتهاب لحماية السيرفر وقاعدة البيانات من أي اختراق أو استهلاك للكوتة المجانية، والملف شغال محلياً على الراسبيري باي بس.
